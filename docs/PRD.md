# 产品需求文档 (PRD)：预测结果 (暂定名)

## 1. 产品愿景与定位
**一句话描述**：一个基于熟人社交圈的「趣味对赌与目标追踪」平台。  
**核心玩法**：用户发起带期限的预测或目标，朋友进行正反面押注，结果揭晓后发放事先承诺的社交奖励。

## 2. 用户痛点与场景
- **目标打卡无趣**：立 Flag 容易倒，缺乏外部朋友的见证和互动。
- **社交群互动单调**：微信群里打赌（比如“今晚湖人能不能赢”、“我一周不喝奶茶”）通常缺乏一个清晰的看板来记录谁压了哪边，最后容易赖账。
- **本产品解决**：将社交对赌、立 Flag 过程 **规范化、游戏化、透明化**，并提供精美的页面供大家分享至朋友圈或微信群。

## 3. 核心角色与功能
### 3.1 发起人 (Creator)
- **发布预测/目标**：填写主题（如“我下个月拿到驾照”）、选项（如 A:能，B:不能）、截止时间点。
- **设定激励**：填写结果产生后的奖惩承诺（如“压中者平分1000欢乐豆” 或 “我请大家喝奶茶”）。
- **多阶段目标 (Phase)**：(进阶需求) 可拆分为多阶段的子节点，每个节点独立结算。
- **结果验证 (AI智能裁判)**：截止日期到达后，如果是客观事实目标，发起人需上传截图凭证（如跑步记录）。系统通过集成视觉大模型（AI裁判）进行客观判定，防止熟人之间耍赖。

### 3.2 参与人 (Voter/Friend)
- **浏览详情**：通过社交分享链接进入，查看预测的背景描述、截止时间和参与人数。
- **选择站队**：在正方面选项中投出自己的一票。长按“盖章”完成下注仪式。
- **全局先知积分**：系统会记录每次投注的胜败，为每位用户计算“预测胜率”与“先知积分”，打造朋友圈里的口碑。
- **围观评论**：(可选) 在下方的弹幕或留言区发送吐槽。
- **接收结果**：结果揭晓时收到提示，并查看自己是否获得了「奖励承诺」。

## 4. 核心页面流转 (User Flow)
1. **首页 (广场/我的)**：查看自己参与或发起的活动列表，展示个人的“先知积分”与胜率看板。
2. **创建页 (Create)**：表单提交 - 选择预测类型 -> 填写信息 -> 提交生成。
3. **分享卡片 (Share)**：生成一张极其精美的高考/打赌分享海报，引导转发。
4. **详情互动页 (Detail)**：显示实时的正反占比（红蓝进度条），下方有大按钮供访客点击投票。长按按钮触发「契约盖章」动效。
5. **结算验证期 (Result Verification)**：倒计时结束时，发起人上传凭证，AI 裁判介入进行鉴权。
   - **公示与复议 (降级方案)**：AI 给出判决结果后进入短时间“公示期”。任何人如不服判决，可点击“要求复议”，将裁决权交还给群组所有参与者进行联名民主投票。以此化解客诉防范机器误判风险。
6. **开奖页 (Winner)**：全屏播放“契约生效”或“撕毁契约”的夸张动画，并展示胜利的一方与瓜分奖励的名单。

## 5. UI/UX 体验要求
- 绝对的 **Mobile-First** (移动端优先)，适配微信内嵌浏览器。
- **丰富微交互**：按钮触碰反馈、进度条动态计算伸展、投票后的震动反馈提示。
- **视觉风格**：年轻化社交调性。推荐浅色模式下采用大圆角卡片+弥散阴影，深色模式采用荧光强调色。

## 6. MVP 迭代规划
- **Phase 1 (MVP)**：支持单节点的一键预测发布、分享链接、朋友访客投票记录、手动决出胜负展示名册。使用简单的用户身份识别体系。
- **Phase 2**：引入系统虚拟货币（或接入真实积分系统），投币押注，按比例结算赔率。
- **Phase 3**：引入多阶段连环目标，排行榜系统等。

## 7. 法律合规与风险提示 (Legal & Compliance Risks)
考虑到产品的主要分发与互动场景是「微信朋友圈」和「微信群」，必须极其谨慎地符合《网络安全法》及《微信外部链接内容管理规范》：

### 7.1 涉赌风险 (核心红线)
**模式判定：** 付出筹码（钱或等价物）尝试猜测未来不确定事件的结果，并借此获取具有经济价值的收益，在我国法律规定中极易被认定为**“聚众赌博”或“开设赌场”。**
- **严禁真实资金资金池**：平台绝对不能代收、代管用户的“押金”或“赌资”。必须采用**完全纯口头承诺**或者**平台无法提现的免费积分**（类似于贴吧经验值），一旦积分可以按比例兑换法币或高价值实物，平台就是涉赌。
- **话术脱敏**：文案上**绝不能使用**“押注、赌局、盘口、赔率、赢钱”等词汇。必须使用“支持、见证、立功、打卡、约定、吃瓜”等正向词汇。

### 7.2 微信诱导分享封号风险
**微信规则：** 微信极度反感“利益诱导分享”（例如：分享到朋友圈领红包、集赞、助力）。
- 如果界面出现类似于“转发此链接到朋友圈，预测对了就能平分1000元”，**微信域名会被秒封止**。
- **规避方案**：产品的分享必须设计得单纯像一个“个人目标的展示”，如“我要挑战一周跑30公里，点击见证！”，并且不能强制访客下载App或强制关注公众号才能参与。

### 7.3 言论审查与欺诈纠纷 (UGC风险)
- **政治与黄赌毒底线**：用户可以自定义预测主题（例如有用户可能去预测某敏感政治事件的结果或股市点数），产品必须接入严格的**敏感词过滤库**，对于公开分享传播的标题更要严审。
- **诈骗风险**：A 承诺“谁投A谁得100块”，随后 A 跑路或者谎称结果不是A，此时受害者可能会投诉到微信，导致你的平台域名由于“被投诉诈骗”而被微信红名拦截。平台应当明确这只是“好友互动的娱乐工具”，不对奖励承诺构成法律上的担保。
